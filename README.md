## 作業說明
這次作業使用 Python 計算聚餐費用，先整理文字資料，再計算服務費、折價券和每人要付的金額，最後判斷有沒有超過預算。

## 執行方式
使用 Google Colab 開啟 `.ipynb` 檔案，依序執行三組測試的程式碼。

## 測試結果
測試一：4 人，折價券 100 元，總額 1220 元，每人 305 元，超過預算 True。

測試二：5 人，折價券 100 元，總額 1220 元，每人 244 元，超過預算 False。

測試三：4 人，折價券 220 元，總額 1100 元，每人 275 元，超過預算 False。

## 問題回答

問題一：為什麼 "4" 要先轉成數字？

因為 "4" 是文字，不能直接拿來做除法，所以要先用 int() 轉成整數才能計算。

問題二：如果先扣折價券再計算服務費，第一組總額是多少？

先用 1200 減掉 100，剩下 1100 元，服務費是 110 元，所以總額會變成 1210 元。因為題目規定服務費要用原始餐費計算，所以正確答案是 1220 元。
